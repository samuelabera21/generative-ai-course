# Week 01 Assignment: Introduction to Python and AI

## Overview

This Week 01 assignment introduces foundational Python programming concepts and basic project organization for AI-related coursework.

## Objectives

The goals of this assignment are to:

- Write and execute a Python script.
- Organize files in a clear project structure.
- Practice version control with Git and GitHub.
- Document the work using professional Markdown.

## Project Structure

```text
week-01/
|-- README.md
|-- assignment.py
|-- requirements.txt
`-- data/
```

### File Descriptions

- **assignment.py**: Main script for the assignment.
- **requirements.txt**: Dependency list for the environment.
- **data/**: Optional folder for datasets.

## Setup Instructions

### 1. Activate a Python Environment

Use one of the following options:

```bash
# Conda
conda activate genai-env

# Virtual environment (Linux/macOS)
source venv/bin/activate

# Virtual environment (Windows PowerShell)
venv\Scripts\Activate.ps1
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

> Note: This assignment may run without external libraries, but installing from `requirements.txt` keeps the setup consistent.

### 3. Run the Program

```bash
python assignment.py
```
